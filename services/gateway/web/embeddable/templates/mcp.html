AI agent connection

Bring your Dropbox into the ONLYOFFICE AI agent

Let the AI agent in ONLYOFFICE Desktop search, read and organize your Dropbox, and open documents in ONLYOFFICE so every edit is saved straight back to Dropbox.

This server is a proxy for Dropbox's official MCP server: every Dropbox tool is passed through as is, plus one extra tool, open_in_onlyoffice, that opens a Dropbox file in ONLYOFFICE Desktop for editing.

Connect in three steps

  1. 1

    Sign in to Dropbox in Desktop

    In ONLYOFFICE Desktop choose Connect to cloud > Dropbox, so files the agent opens load in the editor.

  2. 2

    Open the MCP settings

    Go to AI agent > MCP Servers > Edit configuration.

  3. 3

    Paste and save

    Add the {{ .serverName }} entry to mcpServers, save and restart Desktop. The Dropbox tools appear in the list.

What the agent can do

Every Dropbox tool

Search, list, read, move, copy and share files with the full set of Dropbox MCP tools.

Edit in place

Ask the agent to open a document: it opens in ONLYOFFICE and changes are saved back to Dropbox automatically, with no local copies.

Your permissions only

The agent acts with the access you granted ONLYOFFICE in Dropbox, nothing more.

Keep your key safe

Treat the key like a password.
  • Anyone who has it can use your Dropbox through ONLYOFFICE until {{ .expiresAt }}. A newer key appears on this page before then.
  • Reloading this page shows the same key. If it may have leaked, revoke it: every earlier key stops working at once.
  • To revoke all access, disconnect ONLYOFFICE in Dropbox > Settings > Connected apps.
